- 历史命令和状态不得直接视为当前可执行流程；
- 归档中的 PASS、readiness、Canary 或 Shadow 记录不构成新的测试、外部调用、数据写入或发布授权；
- 历史正文只保存在 `development-history.md`，本索引不复制其内容。
